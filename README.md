# TodoListTest

iOS-приложение — список дел. Тестовое задание.

## Что умеет

- Добавлять задачи (кнопка `+`)
- Редактировать и удалять задачи
- Помечать задачи как выполненные
- Искать по списку
- Делиться задачами
- Отображать общее количество задач
- Хранить всё в Core Data — задачи не пропадают между запусками

## Стек

- **SwiftUI** — интерфейс
- **Core Data** — хранение
- **MVVM** — архитектура
- **URLSession** — при первом запуске подтягивает стартовый список с публичного API, дальше работает локально
- **XCTest** — юнит-тесты

Минимальная версия iOS: 16.0. Без внешних зависимостей — нужно просто открыть `.xcodeproj` файл.

## Как запустить

1. Открыть `TodoListTest.xcodeproj` в Xcode.
2. Выбрать симулятор (например, iPhone 14).
3. `⌘R`.

## Как прогнать тесты

В Xcode: `⌘U`.

Или из терминала:

```sh
xcodebuild -project TodoListTest.xcodeproj -scheme TodoListTest \
  -destination 'platform=iOS Simulator,name=iPhone 14' test
```
